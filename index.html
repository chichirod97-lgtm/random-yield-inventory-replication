摘要

本研究围绕全有或全无随机交付、非零提前期与需求积压的库存控制问题，开展文献方法的部分复现和扩展实验。研究采用24组参数配置、每组3个训练随机种子，比较固定权重启发式 GDSH、采用指数损失的状态依赖网络，以及将其目标改为平均折现成本的网络。最终统一评价使用预先固定的新测试种子1100000，每组配置1000条轨迹。平均损失网络相对 LIR、WNH 的平均成本分别下降5.115%和4.704%；按各配置三种子平均成本计算，其相对 GDSH 的成本平均下降3.340%。但其成本高于同轨迹 WNH 的频率为39.30%，高于指数损失网络的20.68%。结果表明，平均成本改善与相对基准的退步风险应分别评价。本文属于缩减实验网格下的部分复现及目标函数扩展，尚未完整复现原文全部实例或证明策略最优性。

关键词： 库存控制；随机交付；提前期；深度强化学习；样本路径优化；损失函数；可复现性

1. 研究背景与问题

研究对象为有限规划期库存系统。每期首先观察到货及其交付结果，再根据当前库存和在途订单决定订货量，随后实现需求。未满足需求形成积压；采购按实际接收数量付款，并计入期末持有和积压成本。目标是在需求和交付不确定性下控制总折现成本。

基础文献为 Yan 等人的《Heuristics and deep reinforcement learning for the inventory problem with an all-or-nothing yield pattern and non-zero leadtimes》[1]。该文利用 WNH 启发式的结构建立权重参数化策略，并通过神经网络使权重依赖于系统状态。

本研究回答三个问题：第一，当前实现能否在选定配置中取得低于 LIR、WNH 的成本；第二，WNH 初始化及输入缩放对训练表现有何影响；第三，当比较标准是平均成本时，将指数损失替换为平均成本是否改善表现，以及这种改善与风险指标有何关系。

2. 模型与方法

2.1 成本评价

设提前期为 L，规划期为 T，交付成功概率为 p，折现因子为 α。令 I_t 为第 t 期收货后的净库存，d_t 为需求，q_{t-L} 为当期应到订单，y_t∈{0,1} 为其交付结果，则当期成本为：

c_t = c_o q_{t-L} y_t + h max(I_t-d_t,0) + b max(d_t-I_t,0)。

一条轨迹的总成本为 C = Σ_{t=1}^{T} α^(t-1)c_t。各方法使用相同外生需求和交付轨迹进行配对评价。

相对基准的成本差定义为 100×(模型平均成本/基准平均成本−1)，负值表示改善。汇总时对各配置与种子等权取平均，不把全部配置成本先加总后再求比率。

2.2 比较方法

LIR 和 WNH 作为启发式基准。当前项目的 GDSH 使用非负固定权重，通过 softplus 参数化并最小化平均总折现成本，不强制权重和为1。

网络使用三层隐藏层[8,16,16]、ReLU、逐行 Softmax，以及围绕 WNH 权重的区间映射。实现进一步将最终订货量投影到非负区域。主要变体如下：

名称 初始化 输入 损失 精度
precision64 不强制等于 WNH 原始 指数损失 float64
teacher64 初始策略等于 WNH（数值精度范围内） 原始 指数损失 float64
teacher_scaled64 WNH 初始化 按目标库存缩放 指数损失 float64
teacher_scaled64_mean WNH 初始化 同上 平均成本 float64
GDSH 基于 WNH 的固定权重初始化 不采用状态网络 平均成本 float32

指数损失为各训练轨迹 exp(100×(C_model−C_WNH)/C_WNH) 的均值；平均损失直接取 C_model 的均值。指数函数强调相对 WNH 的不利偏差，其优化目标不等同于平均成本，也不等同于绝对成本 CVaR。

公式（3）—（5）的推导与理解

公式（3）：目标库存的近似构造

论文使用的目标库存为

SL=(L+1)μD+k(L+1)σD2+max{L,1}ρY21−ρY2(μD2+σD2),k=Φ−1(bb+h).S_L=(L+1)\mu_D+k\sqrt{(L+1)\sigma_D^2+\max\{L,1\}\frac{\rho_Y^2}{1-\rho_Y^2}(\mu_D^2+\sigma_D^2)},\quad k=\Phi^{-1}\!\left(\frac{b}{b+h}\right).

其中 μD\mu_D 为每期平均需求，σD2\sigma_D^2 为每期需求方差，ρY\rho_Y 为交付系数的变异系数，bb 和 hh 分别为积压和持有成本。目标库存具有“保护期平均需求＋安全库存”的结构。

理解安全系数，可先考虑报童问题：令 XX 为需要覆盖的随机需求，选择 SS 以最小化

G(S)=h𝔼[(S−X)+]+b𝔼[(X−S)+].G(S)=h\,\mathbb E[(S-X)^+]+b\,\mathbb E[(X-S)^+].

对连续需求分布求导：

G′(S)=hFX(S)−b[1−FX(S)].G'(S)=hF_X(S)-b[1-F_X(S)].

令导数为零，得 FX(S*)=b/(b+h)F_X(S^*)=b/(b+h)。若用正态分布近似 XX，则

S*=𝔼[X]+Φ−1(bb+h)Var(X).S^*=\mathbb E[X]+\Phi^{-1}\!\left(\frac{b}{b+h}\right)\sqrt{\operatorname{Var}(X)}.

若需求逐期独立，保护期需求和的均值与方差分别为 (L+1)μD(L+1)\mu_D、(L+1)σD2(L+1)\sigma_D^2。但公式（3）额外包含随机交付的风险修正项；该项是论文沿用既有文献的近似，不能仅用独立需求求和就严格推导出来，也不是有限期 Bellman 方程的精确解。上述报童推导解释分位数结构，不冒充该修正项的原始证明。

对全有或全无交付，Y∼Bernoulli(p)Y\sim\operatorname{Bernoulli}(p)，因此

ρY2=Var(Y)𝔼[Y]2=p(1−p)p2=1−pp,ρY21−ρY2=1−p2p−1.\rho_Y^2=\frac{\operatorname{Var}(Y)}{\mathbb E[Y]^2}=\frac{p(1-p)}{p^2}=\frac{1-p}{p},\qquad \frac{\rho_Y^2}{1-\rho_Y^2}=\frac{1-p}{2p-1}.

这解释当前近似的 p>0.5p>0.5 约束。p→1p\to1 时交付风险修正消失；p↓0.5p\downarrow0.5 时该修正发散，不能无条件外推。Gamma 需求应代入其实际方差 μD×scale\mu_D\times\text{scale}，不能沿用正态需求的标准差参数。

公式（4）：WNH 的交付情景期望

当前收货已并入 ItI_t，尚有 L−1L-1 笔在途订单，其交付情景集合为 𝒪={0,1}L−1\mathcal O=\{0,1\}^{L-1}。对情景 o=(y1,…,yL−1)o=(y_1,\ldots,y_{L-1})，定义缺口

go(st)=[SL−It−∑i=1L−1yiqt+i−L]+.g_o(s_t)=\left[S_L-I_t-\sum_{i=1}^{L-1}y_iq_{t+i-L}\right]^+.

独立同分布的交付成功事件给出

P(o)=p∑iyi(1−p)L−1−∑iyi.P(o)=p^{\sum_i y_i}(1-p)^{L-1-\sum_i y_i}.

对缺口按情景概率求期望，得到论文公式（4）：

qtWNH=∑o∈𝒪P(o)go(st).q_t^{WNH}=\sum_{o\in\mathcal O}P(o)g_o(s_t).

数值例子： 令 L=3L=3、p=0.8p=0.8、SL−It=70S_L-I_t=70，两笔在途订单为40和20。

交付情景 概率 缺口
均失败 0.04 70
仅40成功 0.16 30
仅20成功 0.16 50
均成功 0.64 10

所以 qt=0.04(70)+0.16(30)+0.16(50)+0.64(10)=22q_t=0.04(70)+0.16(30)+0.16(50)+0.64(10)=22。概率期望计算在这些假设下是精确的；把该期望缺口用作订货量仍是一种启发式，不是对动态最优性的证明。一般而言，𝔼[Z+]≠[𝔼Z]+\mathbb E[Z^+]\ne[\mathbb E Z]^+，这也是 WNH 与先用期望交付量计算的 LIR 会出现差异的原因。

公式（5）：从情景概率到可学习固定权重

GDSH 保留同一组缺口函数，把概率替换为待优化系数：

qtGDSH=∑o∈𝒪wj(o)go(st),j(o)=1+∑i=1L−12i−1yi.q_t^{GDSH}=\sum_{o\in\mathcal O}w^{j(o)}g_o(s_t),\qquad j(o)=1+\sum_{i=1}^{L-1}2^{i-1}y_i.

编号 jj 只是二进制情景的索引。取 wj(o)=P(o)w^{j(o)}=P(o) 就得到 WNH，因此 WNH 是该参数化的特殊情形。学习后的权重不必解释为概率；当前代码不要求权重和为1。

GDSH 的权重固定，但 go(st)g_o(s_t) 随库存与在途订单改变，因此订货量仍依赖状态。网络方法进一步把固定权重改为 wj(st)w^j(s_t)，以表达状态相关的决策。

凸性结论的适用范围

在固定状态下，go(st)g_o(s_t) 是常数，订货量对权重是线性的。若某个单步动作价值函数对订货量凸，其与该线性映射的复合也凸。这解释论文命题中的固定状态论证。

但跨期训练时，后续状态本身受同一权重影响；网络参数化、softplus 和最终非负投影也会改变优化形式。因此不能据此直接断言当前端到端神经网络损失全局凸，或 Adam 必然找到全局最优点。

3. 实验设计

3.1 参数与训练

24组配置来自 L∈{2,5}、p∈{0.55,0.70,0.90}、需求分布∈{正态,Gamma}、b/(b+h)∈{0.90,0.95} 的组合。固定 T=50、平均需求10、采购成本2、持有成本1、α=0.99；正态标准差为2，Gamma尺度为1.6。

训练种子为0、1、2，各使用500条固定训练轨迹、100条验证轨迹、300轮训练。Adam学习率从0.003起每轮乘0.98，最低0.0001。统一保留最后一轮模型，不挑选测试上最优种子或检查点。

种子同时影响训练数据、验证数据与网络初始化。GDSH的初始固定权重本身不随种子改变，因此种子间离散程度不完全代表相同来源的随机性。

3.2 探索与后续测试

最初在配置13、21上开展初始化和缩放诊断；随后扩展到24组。平均损失方案先在配置0、12上诊断，并在新测试种子1000000上核查，再扩展到其余22组。最终平均损失网络、指数损失网络 teacher_scaled64 和 GDSH 均在种子1100000、每配置1000条新轨迹上评价。

该新测试在扩展评价前固定，但方案选择已受先前实验启发，不能把整个研究描述为从一开始完全预注册。对“非诊断配置”的分析也不能保证排除了项目更早的探索影响。

3.3 不确定性和验证

配对区间在每组配置内先平均三个固定模型的逐轨迹成本，再对模型均值比率使用影响函数和 t 临界值构造近似95%区间。每个基准另对24次比较作 Bonferroni 校正。这些区间衡量固定训练模型下的测试抽样误差，不覆盖新种子重新训练的全部不确定性。

跨配置共享测试种子，因此本研究不基于配置独立性构造简单全局区间。种子波动另以每配置三个相对成本差的样本标准差、再跨配置取平均描述。

4. 实验结果

4.1 初始化与输入缩放

在测试800000上，precision64、teacher64、teacher_scaled64 相对 LIR 的平均成本差分别为+0.359%、−0.621%、−1.194%。WNH 初始化和缩放改善了汇总表现，但不保证在每个配置上均改善。

同一测试中 GDSH 相对 LIR 为−1.762%，优于三个指数损失网络的平均结果。由此形成后续损失函数诊断，而不是直接认定网络结构无效。

5. 复现核查

7项 NumPy 基础检查、6项 PyTorch 检查及12组 NumPy/PyTorch 初始模型逐轨迹成本比较均通过。小规模有限动作动态规划与穷举期望一致，但没有完成当前已训练网络对连续动作最优解的比较。

最终快照包含360个模型：216个初始网络变体模型、72个 GDSH、6个平均损失诊断模型和66个扩展模型；历史记录均结束于300轮。原清单3614个文件哈希全部匹配，最终评价协议中的216个模型及3个代码文件哈希与快照一致。

用户在 Colab 中重新计算最终216项评价，与保存成本在预设容差内全部一致：GDSH 使用 rtol=1e−5、atol=1e−3，双精度网络使用 rtol=1e−9、atol=1e−7。随后独立检查用户提供的 reevaluation_check_1100000.json：216个唯一组合齐全，全部标记通过，失败列表为空。该次复算在 CPU 上使用 PyTorch 2.11.0+cpu。双精度两变体的最大绝对差均为7.276×10⁻¹²，GDSH为0.0078125，均在记录的逐元素相对与绝对联合容差判据内。最大绝对差不需要单独小于 atol；判据为每个元素的差不超过 atol+rtol×原值绝对值。本检查核对了记录的覆盖与结果，不是再次独立执行全部模型。检查文件已纳入更新后的最终包。

评价复算不能替代完整的从零训练复现。当前环境清单仅记录打包时环境，而非全部历史训练环境。

6. 与论文的差异及解释边界

原文报告432个大规模实例，本研究只覆盖24组；测试样本数由100改为1000；WNH精确初始化、输入缩放、双精度及平均成本目标均需明确标记为实现选择或扩展。最终订货量的非负投影也是与公式表达需要区分的实现细节。

当前 GDSH 强制固定权重非负，与网络的 WNH±δ 区间约束不同。用户报告72个 GDSH 最终模型的648个权重均未超出网络区间；该观察只能排除最终权重越界，不能排除训练路径差异。

平均损失和指数损失网络的对照尽量保持其他设置相同，证据支持本实现中的目标函数效应。GDSH比较还包含数值精度、权重参数化及初始化差异，因此不能将其与网络的全部差距解释为网络结构带来的增益。

本研究未证明最优性、未完成原文全部实例、未验证对真实业务数据的外部有效性。三个训练种子和1000条测试轨迹不足以保证极端风险或所有环境下的效果。测试前已固定部分方案，但整体研究具有连续探索性质。

7. 结论

在当前24组参数和统一新测试上，以平均成本为目标训练的 WNH初始化、输入缩放网络，在平均成本上系统性优于指数损失版本及本项目 GDSH。与此同时，指数损失较好控制相对 WNH 的退步频率和不利偏差。这说明方法评价应同时明确优化目标与风险口径，不能只据平均成本将一种损失称为普遍优越。

本阶段完成了可核查的部分方法复现、训练变体对照及评价复算。后续应优先在新的研究问题和预先固定方案下扩展配置、种子或风险约束，避免围绕已查看测试反复调参。
