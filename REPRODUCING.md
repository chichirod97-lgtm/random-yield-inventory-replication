Author / 作者: **RICHINA ORTANCIA DOMINIQUE（杜米妮）**

## Install / 安装

Python 3.11–3.13 is recommended. Create a virtual environment, activate it using your operating system's instructions, then install:

建议 Python 3.11–3.13，创建并激活虚拟环境后安装：

```sh
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# Linux / Colab terminal: source .venv/bin/activate
python -m pip install -r requirements.txt
```

Colab: clone the repository, change into its directory, and install the requirements. Use `!` before shell commands in notebook cells. No external data or API keys are required. For CUDA, install the appropriate PyTorch build for the runtime using the official PyTorch installation selector before installing the other dependencies. CPU is the historical reference; GPU results need not be bitwise equal.

Colab 中克隆仓库、进入目录并安装依赖；Notebook 的终端命令前加 `!`。无需外部数据或 API 密钥。CUDA 需要适配运行环境的 PyTorch；历史证据来自 CPU，GPU 不保证逐位一致。

The code README records packaging versions Python 3.13.16, NumPy 2.1.3, SciPy 1.16.3, Torch 2.11.0. These are reported provenance, not a complete environment lock for every past training run. `requirements.txt` supplies compatibility ranges, not historical pins.

## Lightweight check / 轻量检查

```sh
python code/verify_summary.py
python code/run_grid.py
```

The first command uses the standard library and checks 216 summary entries and recorded evaluation receipts. It does not retrain or prove all training runs reproducible. The second prints the full configuration plan without importing Torch or starting training.

第一条命令只验证汇总与已保存核查记录，不重新训练；第二条只打印运行计划。

## Training / 训练

```sh
# Pilot: 3 models, one configuration and seed; measure actual wall time first.
python code/run_grid.py --execute --instances 0 --seeds 0 --output runs/pilot
# Full: 24 configurations x 3 seeds x 3 methods = 216 training runs.
python code/run_grid.py --execute --output runs/full
# Optional GPU (different numerical environment): add --device cuda
```

No training was launched during submission preparation. There is no measured full-grid duration in the public evidence. Budget hours to days, a planning allowance rather than a benchmark; measure the pilot first. Approximate full runtime as 216 times mean pilot runtime per model, with extra allowance for L=5 (16 yield scenarios versus 2 at L=2), evaluation and disk I/O. A single CPU or Colab GPU can execute sequentially; an A100 is optional, and float64 throughput and short sequential rollouts determine actual speed. Record runtime, device and package versions before claiming an estimate. Default CPU threads: 1; checkpoint outputs and trajectory arrays require writable disk. The runner refuses to overwrite its output directory.

本次未启动训练。公开证据没有全网格耗时；应预留数小时至数天（仅预算），先运行试验测量。L=5 比 L=2 的情景更多，应额外预留时间。A100 可选；运行结果写入新目录，避免覆盖历史结果。

## Parameters and provenance / 参数与来源

The runner enumerates `(L,p,demand,critical_ratio)` in this order: `[2,5] x [.55,.70,.90] x [normal,gamma] x [.90,.95]`; the last dimension changes fastest. IDs 0–23 are **new canonical IDs**. The historical instance-to-configuration manifest is absent from the public package, so do not align these IDs with the published instance column without recovering that manifest.

网格与报告一致，但公开包未保存历史实例编号映射；新增脚本的编号不得直接视为历史编号。

Fixed: T=50, mean demand=10, normal sigma=2, gamma scale=1.6, ordering cost=2, holding cost=1, backlog cost=9 or 19, discount=.99. Initial inventory/pipeline zero; no orders in final L periods; normal draws clipped at zero. Training seeds 0/1/2 also initialize Python, NumPy and Torch; training path seeds 100000+s, validation seeds 200000+s, final test 1100000. Each configuration uses 500 fixed training paths, 100 validation paths, 1000 test paths, 300 epochs, Adam, max(.0001,.003*.98**epoch); final model selected. Network hidden sizes 8/16/16, ReLU; teacher bounds WNH ± delta (.25 for L=2, .0884 for L=5), output quantity projected nonnegative. GDSH has nonnegative softplus weights and float32 arithmetic; networks use float64, teacher initialization and scaled state.

`exponential_loss` calls the existing `teacher_scaled64` trainer. `mean_loss` uses a **newly reconstructed trainer**, minimizing mean discounted cost with the same network and schedule. Historical mean-loss training source is unavailable in this public repository; exact identity to historical weights is not claimed. GDSH calls the existing trainer. Validation selects no headline checkpoint; the mean-loss trainer therefore omits validation computation. The full run reproduces the documented grid protocol, not an assurance of identical historical numbers. Raw rerun trajectory costs are saved for further analysis; published risk statistics and paired intervals are not regenerated by this entry point.

指数损失调用现有代码；平均损失入口为本次重建，并非找回历史代码。新增入口用于复跑公开协议，不保证精确恢复历史数值或权重。配对区间和风险分析需要后续单独重算。
